# Especificações transversais

Artefatos do Spec Kit que atravessam domínios ou tratam infraestrutura e
governança do produto.

Organize cada feature em um diretório próprio contendo `spec.md`, `plan.md`,
`tasks.md` e checklists conforme aplicável. A coleção está vazia neste baseline;
novas especificações devem ser criadas pelo fluxo do Spec Kit.
