# Documentação do projeto

Documentação transversal ao frontend e backend, seguindo a mesma estrutura documental dos domínios.

Especificações transversais ficam em `specs/`; blueprints arquiteturais ficam em
`architecture/`; casos de uso transversais ficam em `use-cases/`; requisitos
compartilhados ficam em `requirements/`; PRDs transversais ficam em `prds/`; agentes e standards
operacionais do projeto ficam em `agents/`; padrões técnicos e arquiteturais
compartilhados ficam em `standards/`; contratos de API ficam em `api_contracts/`;
decisões ficam em `adrs/`.
