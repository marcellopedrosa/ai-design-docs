# Contratos de API

Interfaces canônicas e versionadas entre produtores e consumidores do produto.

Use um artefato versionado por interface, como
`<boundary>-<interface>-vN.<ext>`, com produtores, consumidores e política de
compatibilidade documentados. A coleção está vazia neste baseline; novos
contratos devem ser adicionados aqui quando aprovados.
