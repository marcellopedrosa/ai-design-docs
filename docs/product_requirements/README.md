# Product Requirements

## Contrato da coleção

- Conteúdo aceito: problema, evidência, público, outcomes, limites, métricas,
  hipóteses, features e mapa de requirements.
- Nomes: `PRD-NNNNN-short-title.md`.
- Estados: `Draft`, `In Review`, `Validated`, `Deprecated`.
- Critério de granularidade: uma iniciativa com problema, público, outcomes e ciclo
  de validação próprios.

PRD aponta para IDs ou seções canônicas de acceptance criteria; não copia o texto
dos critérios, fluxos de use case ou decisão arquitetural. Apenas aprovação humana
registrada pode mudar o status para `Validated`.
