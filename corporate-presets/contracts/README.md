# Contratos herdados

Schemas e exemplos migrados do harness anterior. Não estão integrados ao Spec Kit e não são contratos obrigatórios deste harness. Os formatos de `gate-result`, `readiness-result` e `handoff` representam o processo antigo; não devem ser usados para governar o ciclo atual.

Contratos de produto devem ficar em `../../projeto/docs/contracts/` ou no `docs/contracts/` do domínio aplicável.
