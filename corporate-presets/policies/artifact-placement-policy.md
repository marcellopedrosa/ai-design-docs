# Política de colocação de artefatos

- Artefatos transversais ficam em `projects/docs/`.
- Artefatos específicos ficam em `projects/frontend/docs/` ou `projects/backend/docs/`.
- Artefatos do Spec Kit ficam em `docs/specs/<feature>/` no escopo afetado.
- O core `spec-kit/` nunca é destino de artefatos de produto.
- Uma coleção só existe quando houver conteúdo aplicável e README imediato.
