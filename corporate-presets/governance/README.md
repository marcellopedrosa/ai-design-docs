# Governança corporativa

O [Spec Kit](../../spec-kit/README.md) rege o ciclo de desenvolvimento. As políticas e decisões copiadas do harness anterior são material de referência histórico; seu estado `Active` original não significa ativação neste repositório.

Antes de reutilizar uma política, adapte paths e remova exigências de fases, gates, orquestradores e skills que dupliquem o Spec Kit. A documentação [estrutural](../standards/documentation-structure-standard.md) é a norma local para localização dos artefatos.
