# Corporate presets

Camada corporativa sobre o Spec Kit. Os arquivos aqui foram migrados de `ai-design-docs-old` e devem ser adaptados antes de serem considerados baseline ativo.

- `templates/`: modelos documentais reutilizáveis.
- `standards/`: estrutura documental e standards técnicos aplicáveis.
- `governance/`: políticas e decisões de governança.
- `contracts/`: schemas legados mantidos apenas como referência.
- `skills/`: fonte das skills corporativas publicadas nos diretórios nativos dos agentes.

O ciclo de desenvolvimento é regido por `../spec-kit/`. Materiais herdados do harness antigo que ainda mencionem C.L.E.A.R., readiness, quality gate ou AgentOrchestrator são históricos e não devem ser ativados como processo corporativo. Antes de adotar qualquer outro documento migrado, confira suas referências e compatibilidade com o Spec Kit.
