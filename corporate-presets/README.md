# Corporate presets

Camada corporativa complementar ao Spec Kit. O conteúdo desta pasta define convenções reutilizáveis sem substituir o ciclo de especificação, planejamento, execução e validação do Spec Kit.

- `templates/`: modelos documentais reutilizáveis.
- `standards/`: estrutura documental e standards técnicos aplicáveis.
- `skills/`: fonte das skills corporativas publicadas nos diretórios nativos dos agentes.

O ciclo de desenvolvimento é regido por `../spec-kit/`. Templates, standards e skills corporativas devem complementar esse processo sem criar fases, gates ou artefatos concorrentes.
