# Agentes do projeto

Esta coleção define papéis que ajudam a interpretar o contexto do projeto. O [orquestrador](orchestrator.md) é a porta de entrada documental para selecionar escopo, fontes e processo do Spec Kit.

Uma definição nesta pasta não instala automaticamente um agente no runtime. A integração com Codex, Copilot ou outro agente deve ser configurada e verificada separadamente.
