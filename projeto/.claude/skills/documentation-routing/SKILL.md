# Roteamento documental

Use quando o pedido envolver criar, mover ou atualizar documentação do produto e houver dúvida sobre qual `docs/` recebe o artefato.

1. Leia o `AGENTS.md` do projeto e o do domínio afetado, quando existir.
2. Se o projeto tiver `corporate-presets/standards/documentation-structure-standard.md`, use-o como catálogo de coleções e destinos. Se não estiver presente, use as regras documentais locais do projeto e informe a lacuna.
3. Escolha `docs/` do projeto para conteúdo que afeta vários domínios; escolha `<domínio>/docs/` para conteúdo exclusivo daquele domínio.
4. Para artefatos do Spec Kit, confirme o destino real suportado pela instalação antes de afirmar que a gravação em `docs/specs/` é automática.
5. Aponte o destino e as fontes consultadas. Não crie fases, gates ou artefatos paralelos aos comandos do Spec Kit.
